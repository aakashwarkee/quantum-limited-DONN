# Quantum-limited imaging using diffractive optical neural networks

Code for the figures of

> Aakash Warke, Aonan Zhang, and A. I. Lvovsky,
> *Quantum-limited imaging using diffractive optical neural networks*,
> [arXiv:2608.12300](https://arxiv.org/abs/2608.12300).

## Contents

| Notebook | Reproduces |
|---|---|
| `WZL_Fig1.ipynb` | Fig. 1 — single-parameter estimation: direct imaging vs the quantum bounds (QCRB = NHCRB), with the DONN saturating the quantum limit across the band |
| `WZL_Fig2.ipynb` | Fig. 2 — two-parameter estimation: the bound hierarchy QCRB ≤ NHCRB ≤ SLD-ansatz, with the DONN tracking the NHCRB |
| `WZL_Fig3.ipynb` | Fig. 3 — attainability for $M$ jointly estimated amplitudes, and the per-parameter variance split at $M = 15$ |
| `WZL_Fig4.ipynb` | Fig. 4 — 2-D imaging: cell-like pattern, atom array, and diatom (SEM image), DONN vs direct imaging with the same matched estimator |

Each notebook is self-contained (optics → bounds → DONN training → Monte Carlo → figure) and writes its outputs to `figures/` and `data/`.

## Running

```
pip install -r requirements.txt
```

Cells marked **[slow]** train the DONNs (a CUDA GPU is used automatically if available; the NHCRB semidefinite programs are memory-heavy). Every other cell — including the figure cells marked **[fast]** — only reads the `.npz` files in `data/`, so all figures can be regenerated from the precomputed data without a GPU.

## Data

`data/SEM_orig.npy` is the SEM image behind the diatom row of Fig. 4. The remaining files in `data/` are the precomputed results each figure reads. `data/WZL_Fig4_device.npz` is a large training cache (~120 MB) used only to re-derive the Fig. 4 object rows without retraining; it is regenerated by the corresponding **[slow]** cell.
